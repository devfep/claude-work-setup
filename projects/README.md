One folder per team repository, named exactly like its checkout under `PROJECTS_DIR`.
Each holds that repo's `CLAUDE.local.md` (from `protocol/templates/CLAUDE.local.*.md`) and,
under `skills/verify-<repo>/`, the verification skill generated by `/create-verification-skill`.
bootstrap.sh symlinks the file into the checkout (excluded via `.git/info/exclude`) and the
skill into `~/ebs/.claude/skills/`. The generic repo ships none; the firm fork adds them.
